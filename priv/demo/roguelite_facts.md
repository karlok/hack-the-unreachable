# Demo game fact sheet (simulated builder)

- Working title: Ember Depths. A top-down action roguelite: short runs through procedurally generated caverns, permadeath, a hub with meta-progression unlocks between runs.
- Engine: BabylonJS, TypeScript, built with Vite. Runs in the browser, desktop first. Mobile browsers are a stretch goal, not promised for 1.0.
- Solo developer, part-time, aiming to ship 1.0 in about four months.
- Single-player only. No multiplayer, no leaderboards at launch, no accounts.
- English only for 1.0. Might localize later if it sells.
- Sold directly from my own website for $8 through a payment provider (Stripe or Paddle). Not on Steam, itch.io or app stores for 1.0.
- Save data is local to the browser. No cloud saves.
- Controls: keyboard and mouse, plus gamepad through the browser Gamepad API.
- Light story: a few lore notes and an ending text screen. No voice acting, no cutscenes.
- Pixel-art style sprites on 3D low-poly levels. Original music commissioned from a friend.
